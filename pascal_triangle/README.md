# Pascal's Triangle

This project implements Pascal's Triangle in Python.

## Description

The `pascal_triangle` function returns a list of lists of integers representing Pascal's Triangle up to `n` rows.

If `n` is less than or equal to `0`, the function returns an empty list.

## Prototype

```python
def pascal_triangle(n):
```

## Example

For `n = 5`, the function returns:

```text
[
    [1],
    [1, 1],
    [1, 2, 1],
    [1, 3, 3, 1],
    [1, 4, 6, 4, 1]
]
```
